# 🎉 Submitti 🎉

Makes confetti explode whenever you submit an assignment on Schoology because surviving
schoolwork deserves celebration :)

## what it does

Every time you submit an assignment on Schoology, the extension launches confetti on your screen

## why I made this
After spending hours on homework assignments, I wanted a celebration/dopamine spike when I'm done.

## features

- 🎊 confetti
- ⚡ works automatically in your browser
- 😎 makes homework slightly less painful
- 🧠 scientifically increases happiness by at least 400%

## installation

1. Download or clone this repository

```bash
git clone https://github.com/raahini07/submitti-extension.git
```

2. Open Chrome and go to

```text
chrome://extensions
```

3. Turn on **Developer Mode**

4. Click **Load unpacked**

5. Select the extension folder

6. Go submit something on Schoology and enjoy the confetti
